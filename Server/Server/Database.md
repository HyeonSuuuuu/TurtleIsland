# 서버 DB(MSSQL) 설정

DB 구성은 저장소의 `Server/TurtleIsland.bak` 백업을 복원해서 사용합니다.
서버 실행 파일은 백업을 직접 읽거나 DB를 자동으로 구성하지 않습니다.

## 백업 복원

1. SQL Server와 SSMS를 준비합니다. 백업을 복원할 수 있는 SQL Server 버전을 사용합니다.
2. SSMS에서 데이터베이스 복원을 선택하고 장치에 `Server/TurtleIsland.bak`을 지정합니다.
3. 대상 DB 이름을 `TurtleIsland`로 지정하고 데이터·로그 파일 경로를 확인합니다.
4. 기존 DB가 있다면 먼저 별도로 백업합니다. 기존 DB 덮어쓰기는 명시적으로 결정합니다.
5. SQL Server 서비스 계정이 백업 파일을 읽을 수 있는지 확인한 뒤 복원을 진행합니다.

백업에는 현재 로그인 코드가 사용하는 `dbo.Account`, `dbo.usp_Account_Load`,
`dbo.usp_Account_Save`가 포함되어 있어야 합니다. 복원 후 서버와의 호환성을 확인합니다.
계정 조회는 `AccountId, PwHash`를, 신규 등록은 생성된 `AccountId`를 반환해야 합니다.

## 서버 연결

기본 연결 문자열은 `Database.h`의 `DbConfig::DEFAULT_CONN`에 설정된
`DSN=TurtleIsland;`입니다. 64비트 ODBC 데이터 원본에서 해당 DSN이 복원한 DB를
가리키도록 설정합니다. 실행 계정에 DB 접근 권한이 있어야 합니다.

다른 연결 설정은 서버 실행 환경의 `TI_DB_CONN`으로 지정할 수 있습니다.
인증 정보는 저장소에 기록하지 않습니다.

## 실행 동작

- 서버는 복원된 DB에 연결해 기존 계정 조회·신규 계정 등록 프로시저를 호출합니다.
- DB 연결 실패 시 인증을 통과시키는 기존 프로토타입 폴백은 그대로입니다.
  운영 환경에서 실행하기 전에 DB 연결 성공 여부를 반드시 확인합니다.
- 백업에는 계정 데이터가 포함될 수 있으므로 외부 공유나 저장소 업로드 전에 내용을 확인합니다.
